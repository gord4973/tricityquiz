# 2027 Eclipse Sportback Sales Guide Quiz

id `eclipse-sportback-2027-training`
Source: /workspace/uploads/training-guides/Eclipse-Sportback-Sales-Guide.pdf (9 pp; title year 2027; prices per mitsubishi-motors.ca as of November 2026)

1. What type of vehicle is the 2027 Eclipse Sportback?  
   Answers: Plug-in hybrid / Mild hybrid / All-electric / Gasoline only  
   **Correct: All-electric** (guide p1 cover)
2. How many seats does every Eclipse Sportback have?  
   Answers: 4 / 5 / 6 / 7  
   **Correct: 5** (guide p2 At a Glance)
3. What drivetrain does the Eclipse Sportback use?  
   Answers: AWD / RWD / 4WD Lock / Front-wheel drive  
   **Correct: Front-wheel drive** (guide p2)
4. How much horsepower does the Eclipse Sportback make?  
   Answers: 181 hp / 214 hp / 248 hp / 174 hp  
   **Correct: 214 hp** (guide p2)
5. How much torque does the Eclipse Sportback make?  
   Answers: 206 lb-ft / 245 lb-ft / 261 lb-ft / 332 lb-ft  
   **Correct: 261 lb-ft** (guide p2)
6. What size is the Eclipse Sportback battery?  
   Answers: 50 kWh / 60 kWh / 75 kWh / 90 kWh  
   **Correct: 75 kWh** (guide p2)
7. Estimated range on a full charge?  
   Answers: 350 km / 400 km / 454 km / 500 km  
   **Correct: 454 km** (guide p2-3)
8. Cargo space behind the rear seats?  
   Answers: 308 L / 566 L / 866 L / 1,062 L  
   **Correct: 566 L** (guide p2)
9. Max cargo with seats folded?  
   Answers: 1,200 L / 1,572 L / 1,822 L / 2,040 L  
   **Correct: 1,572 L** (guide p2)

   Answers: 5 yr / 100,000 km / 7 yr / 120,000 km / 10 yr / 160,000 km / 10 yr / 200,000 km  
   **Correct: 10 yr / 160,000 km** (guide p2, p9)
11. Combined efficiency rating?  
   Answers: 1.9 Le/100 km / 2.1 Le/100 km / 2.3 Le/100 km / 2.5 Le/100 km  
   **Correct: 2.1 Le/100 km** (guide p2-3)
12. City / highway efficiency?  
   Answers: 1.9 city, 2.3 highway / 2.1 city, 2.1 highway / 2.3 city, 1.9 highway / 1.7 city, 2.5 highway  
   **Correct: 1.9 city, 2.3 highway** (guide p3)
13. Max DC fast-charge rate?  
   Answers: 50 kW / 100 kW / 150 kW / 250 kW  
   **Correct: 150 kW** (guide p2-3)
14. Which DC charge connector does it use?

15. DC fast charge 10–80% time?

   **Correct: About 6.5 hours** (guide p3)
17. Which charging cord is included?  
   Answers: DC fast-charge cable only / Portable Level 1/Level 2 cord / None — sold separately / Wallbox home charger  
   **Correct: Portable Level 1/Level 2 cord** (guide p3)
18. What climate hardware is standard on every Eclipse Sportback?  
   Answers: PTC heater only / Heat pump only / PTC heater and heat pump / No heat pump available
